# CyberRange agent instructions

## Frontend theme contract

Before changing any user-facing frontend in `backup/`, read
[`backup/FRONTEND_CONTRACT.md`](backup/FRONTEND_CONTRACT.md), then use
[`backup/DESIGN.md`](backup/DESIGN.md) as the visual source of truth and
[`backup/PRODUCT.md`](backup/PRODUCT.md) for product constraints.

The Clay Range is the established CyberRange visual direction. Do not introduce
a separate visual language, palette, illustration style, or component pattern
unless the user explicitly asks to change the theme contract.
